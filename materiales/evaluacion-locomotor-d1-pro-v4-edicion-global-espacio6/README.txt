EVALUACIÓN APARATO LOCOMOTOR · 6.º EP · V2

10 ejercicios.

NIVEL
-----
Ejercicios 1-7:
- nivel medio-alto
- clasificación, relación, selección múltiple, secuenciación y aplicación

Ejercicios 8-10:
- nivel sencillo-medio
- respuestas breves de desarrollo
- definición, diferencia básica y prevención

PREGUNTAS ABIERTAS
------------------
8. Define qué es un tendón y qué une.
9. Explica una diferencia entre tendón y ligamento.
10. Escribe dos medidas para prevenir lesiones.

ALEATORIEDAD
------------
- Las opciones de elección se barajan en cada carga.
- Las opciones de selección múltiple se barajan en cada carga.
- En relacionar se barajan de forma independiente las dos columnas.
- En clasificar se barajan tanto los elementos como el orden visual de las categorías.
- En ordenar/secuenciar se barajan las tarjetas de respuesta.

PUNTUACIÓN
----------
- 7 ejercicios automáticos = 7 puntos
- 3 desarrollos = 3 puntos pendientes de corrección manual

D1
--
- Validación remota obligatoria
- Sin lista local de alumnado
- Respuestas abiertas completas guardadas en events
- Nota provisional hasta revisar las 3 preguntas abiertas

activityId:

V3 · MEJORA DE INTERACCIÓN
--------------------------
- En RELACIONAR se puede crear una pareja aunque sea incorrecta.
- Las selecciones izquierda/derecha se muestran claramente resaltadas.
- Las parejas creadas aparecen debajo en "Tus relaciones".
- Cada pareja puede cambiarse antes de guardar la respuesta.
- Botón "Cambiar / reiniciar" disponible en los ejercicios autocorregibles.
- El alumno puede modificar cualquier respuesta mientras no pulse "Guardar respuesta".
- Una vez guardada, la respuesta queda bloqueada y se pasa al siguiente ejercicio.


V4 · EDICIÓN GLOBAL ANTES DE GUARDAR
------------------------------------
Regla aplicada a TODAS las actividades:
- elección única: puede cambiar de opción;
- selección múltiple: puede marcar/desmarcar;
- relacionar: puede crear parejas, equivocarse y cambiarlas;
- clasificar: puede volver a seleccionar y mover elementos;
- ordenar/secuenciar: puede reiniciar el orden;
- desarrollo: puede editar libremente el texto;
- botón "Cambiar respuesta" disponible antes de guardar.

Solo al pulsar "Guardar respuesta":
- la actividad queda bloqueada;
- desaparece la opción de cambio;
- aparece "Siguiente".
