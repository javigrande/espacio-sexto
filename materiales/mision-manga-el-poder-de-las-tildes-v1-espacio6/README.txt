MISIÓN MANGA · EL PODER DE LAS TILDES · V1
========================================

Juego web HTML/CSS/JavaScript para Espacio 6.º (GitHub Pages).

INSTALACIÓN:
1. Descomprime el ZIP.
2. Sube la carpeta completa tal cual al repositorio de tu web.
3. Abre index.html desde GitHub Pages.

Incluye 5 misiones de 5 preguntas cada una (25 en total):
1. Dojo del Acento: preguntas de elección.
2. Portal de las Palabras: elige con tilde/sin tilde.
3. Viñetas en Acción: reescribe diálogos y corrige signos y tildes.
4. Arena de los Dos Poderes: preguntas indirectas y relativos.
5. Jefe Final: mezcla de desafíos.

Funciones: progreso, aciertos, puntos, combo, energía visual, efectos de sonido
opcionales, pantalla completa, rutas desbloqueables, guardado local, rango final.
No depende de servidores ni claves. No envía información de alumnos a D1.

Las imágenes manga se incluyen en assets/ como WEBP optimizado.
Todas las respuestas de gramática son contenido original de esta actividad.
Para evitar que los dispositivos dependan de Google Fonts, las fuentes tienen
fallbacks de sistema y la web funciona sin conexión tras cargar los archivos.
